# DockWatch Documentation

Welcome to DockWatch, a real-time Docker container monitoring and management dashboard.

## Overview
DockWatch provides real-time monitoring, auto-recovery, and management for Docker containers.

## Quick Start
```bash
./start.sh
```

## Access
- **Dashboard**: http://localhost:3001
- **API**: http://localhost:3001/api
- **Health**: http://localhost:3001/api/health

## Default Credentials
- **Username**: `admin`
- **Password**: `admin123` (development only)
