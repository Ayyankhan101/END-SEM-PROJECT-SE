# Plan: Implement Remaining Features for Smart Docker Monitoring System

## Overview
This plan outlines the implementation of 4 remaining backlog features. The project is a Docker container monitoring system with:
- **Backend**: FastAPI (Python) with SQLite database
- **Frontend**: React + Vite with Tailwind CSS
- **Real-time**: WebSocket for live updates

---

## Feature 1: Container Log Viewing

### Description
Add real-time log viewing capability for containers in the UI.

### Implementation Steps

#### Backend (Python/FastAPI)
1. **Add log endpoint** in `app/api/endpoints.py`:
   - `GET /api/containers/{id}/logs` - fetch container logs
   - Support query params: `lines` (default 100), `follow` (streaming)

2. **Add log method** in `app/services/docker_monitor.py`:
   - `get_container_logs(container_id, lines=100)` - fetch logs via Docker API

#### Frontend (React)
3. **Create LogViewer component** in `src/components/LogViewer.jsx`:
   - Display logs in scrollable terminal-style view
   - Auto-scroll to bottom, pause on scroll up
   - Refresh button

4. **Add Logs tab** in `src/pages/ContainerDetail.jsx`:
   - Add tab navigation (Overview | Logs)
   - Integrate LogViewer component

## Feature 2: Multi-host Docker Monitoring

### Description
Add support for monitoring Docker containers across multiple Docker hosts.

### Implementation Steps

#### Backend
1. **Add Host model** in `app/db/models.py`:
   - Fields: id, name, socket_path, api_version, status, last_seen

2. **Add Host endpoints** in `app/api/endpoints.py`:
   - `GET /api/hosts` - list all hosts
   - `POST /api/hosts` - add new host
   - `DELETE /api/hosts/{id}` - remove host

3. **Update DockerMonitor** in `app/services/docker_monitor.py`:
   - Support multiple host connections
   - Add host parameter to methods

4. **Add host management page data** to API

#### Frontend
5. **Create HostList page** in `src/pages/Hosts.jsx`:
   - List connected hosts with status
   - Add/remove hosts UI

6. **Update Dashboard** to show containers from all hosts:
   - Add host indicator on containers
   - Filter by host

---

## Feature 3: Container Create/Deploy Feature

### Description
Allow users to create new containers or deploy from docker-compose files.

### Implementation Steps

#### Backend
1. **Add container creation endpoints** in `app/api/endpoints.py`:
   - `POST /api/containers` - create new container
   - Parameters: image, name, ports, volumes, environment

2. **Add create_container method** in `app/services/docker_monitor.py`:
   - `create_container(config)` - create and start container

3. **Add docker-compose support**:
   - `POST /api/stacks/deploy` - deploy compose file
   - Parse and validate compose file
   - Create all services

#### Frontend
4. **Create ContainerCreate page** in `src/pages/ContainerCreate.jsx`:
   - Form with fields: image name, container name, port mappings, volumes
   - Image search/pull option

5. **Create StackDeploy page** in `src/pages/StackDeploy.jsx`:
   - File upload for docker-compose.yml
   - YAML editor with syntax highlighting
   - Deploy button with confirmation

6. **Add navigation** in `src/App.jsx`:
   - Routes for `/containers/new` and `/stacks/deploy`

---

## Feature 4: Docker Compose Stack Management

### Description
Enable creating, editing and deploying Docker Compose stacks from the UI.

### Implementation Steps

#### Backend
1. **Add Stack model** in `app/db/models.py`:
   - Fields: id, name, compose_file, status, created_at

2. **Add Stack endpoints** in `app/api/endpoints.py`:
   - `GET /api/stacks` - list stacks
   - `POST /api/stacks` - create stack
   - `DELETE /api/stacks/{id}` - remove stack
   - `POST /api/stacks/{id}/start` - start stack
   - `POST /api/stacks/{id}/stop` - stop stack

3. **Add stack operations** in `app/services/docker_monitor.py`:
   - Parse compose file
   - Deploy/start/stop stack using docker-compose or API

#### Frontend
4. **Create Stacks page** in `src/pages/Stacks.jsx`:
   - List all stacks with status (running/stopped)
   - Start/Stop/Remove buttons
   - View services in stack

5. **Create StackDetail page** in `src/pages/StackDetail.jsx`:
   - Show stack compose content
   - List containers in stack
   - Edit compose file option

6. **Add navigation** in `src/App.jsx`:
   - Route for `/stacks`
